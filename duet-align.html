      How this works
      
        While Duet records, both phones add the same pair of rising chirps to their files at agreed moments: at the start, every few minutes, after any interruption, and just before the end. This page decodes each file at 16 kHz, finds every chirp pair with a matched filter, pairs them up between the two recordings, and maps each recording onto one shared timeline through those points. That corrects the small speed difference between the phones' clocks, and if a phone stopped recording for a while (for example the screen locked), the missing stretch is filled with silence instead of shifting everything after it.
        
      
        As a double-check it compares each person's own microphone with how the other phone heard them over the call; that copy should trail by the call's delay, usually 50–300 ms.
        
      
        The exported files start at whichever recording began first; the other track starts with a little silence, so no audio is cut. If a phone dropped out and rejoined, add its _part2 file too. Mic-only backup files have no chirps and are skipped.
        
      
        Long calls: a 1-hour call needs roughly 1–2 GB of memory while decoding. Desktop Chrome or Safari is best.
